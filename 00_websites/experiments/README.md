# Website experiments

This folder preserves website prototypes that are useful but are not part of
the current five formal exhibition surfaces.

- Move a rejected or superseded prototype here instead of deleting it.
- Keep each experiment self-contained in its own folder.
- Do not point the Control Room's `01`, `02`, or `03` buttons here.
- Remove or rename formal page heartbeats when archiving a prototype so it
  cannot impersonate the current page.
- Shared raw video remains in `05_shared_data`; do not duplicate it here.

Current preserved experiments:

- `reaction_diffusion` — WebGL reaction-diffusion visual study.
- `generation_ice_crystal_01` — earlier browser-based 3D crystal generation study.
