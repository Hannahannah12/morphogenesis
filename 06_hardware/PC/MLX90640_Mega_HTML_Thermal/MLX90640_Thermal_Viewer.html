连接方法
  1. 先把配套的 MLX90640_Mega_Stream.ino 上传到 Mega。
  2. 关闭 Arduino 串口监视器，否则网页打不开同一个 COM 口。
  3. 使用桌面版 Chrome 或 Edge 打开本页，点击“连接 Mega”，选择 Mega 的 COM 口。
  4. 如果浏览器不允许本地 HTML 使用串口，可在此文件目录运行 python -m http.server 8000，再打开 http://localhost:8000/MLX90640_Thermal_Viewer.html。
